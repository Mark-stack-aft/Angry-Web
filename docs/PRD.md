# [PRD] Angry Web (사이트 방문 제한 프로그램)

## 1. 개요 (Overview)

* **프로그램 명:** Angry Web
* **목적:** 지정된 블랙리스트 패턴에 따라 사용자 유해/몰입 방해 사이트 접속을 차단하고, 임의 해제나 강제 종료를 방지하여 생산성을 유지하는 로컬 보안 웹 필터링 프로그램.
* **타겟 환경:** Windows PC (관리자 권한 설치)

---

## 2. 권장 기술 스택 (Tech Stack)

* **백그라운드 서비스 및 필터링 엔진:** **Go** 또는 **C# (.NET)**
* 이유: Windows 서비스(Service) 등록이 용이하고, 로컬 프록시(Proxy) 서버를 가볍고 빠르게 구축하여 HTTPS 트래픽 검사 및 패턴 매칭을 처리하기에 적합합니다.


* **UI 및 차단 페이지:** **HTML / CSS / JavaScript (Electron 또는 Local Web Server 방식)**
* 로컬 포트(예: `127.0.0.1:port`)를 통해 차단 페이지를 서빙하고, 프록시가 차단 시 해당 페이지로 리다이렉트합니다.



---

## 3. 핵심 기능 명세 (Core Features)

### ① 라이프사이클 및 시스템 보호

* **자동 부팅 연동:** 설치 시 Windows 레지스트리(`Run` 또는 Windows Service)에 등록되어 PC 부팅 시 백그라운드에서 자동 실행됩니다.
* **강제 종료 방지:** 관리자 권한으로 실행되는 서비스로 등록되어, 작업 관리자 등에서의 임의 강제 종료를 방지합니다. (종료 시 비밀번호 요구)
* **제거 방지:** 프로그램 언 설치(Uninstallation) 시 설정된 마스터 비밀번호를 필수로 요구합니다.

### ② 깃허브(GitHub) 연동 및 동기화

* 프로그램 구동 시 및 주기적으로 지정된 깃허브 저장소에서 **차단 주소 목록**과 **차단 페이지 안내 문구**를 JSON/Markdown 형태로 페치(Fetch)합니다.

### ③ 고급 패턴 매칭 엔진 (Pattern Matching)

제안하신 다양한 규칙을 정규식(Regex) 또는 파서(Parser)로 변환하여 처리합니다.

* `주소/` $\rightarrow$ 정확히 해당 경로만 차단
* `주소/*` $\rightarrow$ 해당 주소 및 하위 모든 경로 차단
* `*.주소/*` $\rightarrow$ 와일드카드 서브도메인 및 하위 경로 차단
* `*주소*` / `주소*` $\rightarrow$ 키워드 포함 및 접두사 매칭 차단
* `주소/ (++ 키워드1 ++ 키워드2) | 키워드3` $\rightarrow$ 복합 조건식 파싱 (AND/OR 연산 처리)

### ④ 차단 페이지 및 우회 메커니즘

* **스타일/문구:** 깃허브에서 가져온 차단 문구를 출력하며, 접속하려던 원래 페이지의 기본 테마(CSS)를 유추하거나 유사하게 렌더링하여 이질감을 줄입니다.
* **일시 해제:** 차단 페이지 내에 비밀번호 입력창을 제공하여, 올바른 비밀번호 입력 시 일정 시간 동안 해당 사이트 접속을 허용합니다.

## 4. 시스템 아키텍처 구상안

```
[사용자 브라우저] 
      │ (HTTPS/HTTP 요청)
      ▼
[Angry Web 로컬 프록시 서버 (Local Proxy)] 
      ├─> 깃허브 블랙리스트와 패턴 비교
      │     ├── [매치 안 됨] ──> 정상 사이트로 연결
      │     └── [매치 됨]   ──> 로컬 차단 페이지로 리다이렉트 (비밀번호 입력창 제공)
      └─> 비밀번호 검증 성공 시 ──> 예외 리스트에 일시 등록 후 통과

```
