# Angry Web (사이트 방문 제한 프로그램)

집중력 유지와 유해/도파민 유발 사이트 차단을 위한 로컬 보안 필터링 솔루션입니다.

---

## 🚀 주요 기능
1. **Windows 서비스 및 강제 종료 방지**
   - 시스템 부팅 시 자동 시작 (`start= auto`)
   - 서비스 중지(`stop`) 및 제거(`uninstall`) 시 마스터 비밀번호 인증 요구
   - 프로세스 종료 시 자동 재시작(Failure Recovery) 정책 적용

2. **고급 패턴 매칭 엔진**
   - `주소/` : 정확히 해당 주소(루트 경로)만 차단
   - `주소/*` : 해당 주소 및 모든 하위 경로 차단
   - `*.주소/*` : 모든 서브도메인 및 하위 경로 차단
   - `*주소*` / `주소*` : 키워드 포함 및 접두사 차단
   - `주소/ (++ 키워드1 ++ 키워드2) | 키워드3` : AND/OR 복합 조건식 파싱 차단

3. **HTTPS 로컬 프록시 & 자동 루트 인증서**
   - 브라우저 트래픽 가로채기 및 대상 규칙 일치 시 안내 차단 페이지로 리다이렉트
   - Titanium Proxy 기반 시스템 프록시 자동 연동

4. **GitHub 실시간 원격 동기화**
   - 지정된 GitHub 저장소(`rules.json`)로부터 주기적(기본 10분)으로 차단 규칙 및 차단 페이지 문구 동기화

5. **임시 해제 메커니즘**
   - 차단 화면에서 마스터 비밀번호 인증 시 5분~1시간 동안 접속 임시 허용

---

## 🛠 설치 및 사용 방법 (순정 Windows PC 지원)

### 🌟 초간단 설치 (GUI 설치 마법사 - 추천)
Node.js, .NET 등 아무것도 설치되어 있지 않은 PC에서도 더블 클릭으로 설치할 수 있습니다:
1. `dist/installer/AngryWeb.Installer.exe` 실행
2. 원하는 **마스터 비밀번호** 설정 (기본값: `angryweb`)
3. **[지금 설치하기]** 버튼 클릭
   - 백그라운드 Windows 서비스(`AngryWebService`)로 자동 등록
   - PC 재부팅 시에도 백그라운드 자동 유지
   - 프로세스 강제 종료 시 자동 복구 정책 작동

> **안전한 제거(Uninstall) 방지:**  
> 프로그램 삭제 시에도 설치 마법사에서 올바른 마스터 비밀번호를 입력해야만 제거가 가능합니다.

### 💻 개발 및 테스트 직접 실행 (개발 환경)
```powershell
# 콘솔 모드 직접 구동
cd src/AngryWeb.Service
dotnet run

# 단위 테스트 실행 (패턴 엔진 검증)
cd tests/AngryWeb.Tests
dotnet test
```
